# 글자 추출(OCR) 방법과 결과

## 방법: PDF 텍스트 + PaddleOCR 하이브리드

1. **PDF 좌표 텍스트 우선 사용** — `pymupdf`로 PDF를 열어 `get_text("dict", sort=True)`로 각 줄의 텍스트와 좌표(bbox)를 좌표순으로 추출. 텍스트층이 정상인 페이지는 이 값을 신뢰도 1.0으로 기본 소스로 둠.
2. **PaddleOCR로 보강** — 200 DPI로 렌더링한 페이지 이미지를 PaddleOCR(PP-OCRv5, 검출 모델 `PP-OCRv5_server_det` + 한국어 인식 모델 `korean_PP-OCRv5_mobile_rec`, GPU)로 OCR.
3. **중복 제거** — 텍스트층이 정상인 페이지에서는 PaddleOCR 결과 중 PDF 텍스트와 겹치는 영역(bbox 겹침비율 ≥ 0.25) 또는 정규화 후 포함 관계인 텍스트는 버리고, PDF에 없던 것만 추가. 텍스트층이 없거나(`없음`) 글꼴이 깨진(`글꼴깨짐`) 페이지는 PaddleOCR만으로 전체 처리.
4. **읽기 순서 복원** — PDF 텍스트 + OCR 추가분을 합쳐 y좌표(8px 단위) → x좌표 순으로 재정렬.
5. **표 행 묶기** — y좌표 허용오차 12px 안의 항목을 같은 행으로 묶어 `" | "`로 셀을 연결.
6. **검토 플래그** — 텍스트층이 정상인데 OCR이 새로 추가한 글자는 `needs_review`로 표시해 사람 검토 대상으로 분리.

핵심 원칙: **텍스트층이 정상이면 PDF 텍스트를 그대로 쓰고, 빠진 부분만 OCR로 메우고, 텍스트층이 깨졌으면 전체를 OCR로 대체**.

## 결과 (`data/pages/version2`, 20개 문서 기준)

| 지표 | 값 |
|---|---|
| 처리 문서 수 | 20 |
| 총 페이지 수 | 241 |
| PDF+OCR 혼합 처리(`pdf_plus_paddle`) 문서 | 17 |
| OCR 전체 처리(`paddle_full_page`) 문서 | 3 |
| PaddleOCR이 새로 추가한 줄 수 | 1,729 |
| 사람 검토 필요(`needs_review`) 줄 수 | 193 |

- 문서 17개는 PDF 텍스트층이 정상이라 PDF 텍스트를 기본으로 쓰고 OCR로 빠진 부분만 보강했음.
- 문서 3개(`paddle_full_page`)는 텍스트층이 없거나 깨져서 전체를 PaddleOCR로 처리했음.
- 추가된 1,729줄 중 193줄(약 11%)은 "정상 텍스트층 페이지에서 OCR이 새로 끼워 넣은 글자"라 사람 검토 대상으로 표시됨. 나머지는 텍스트층이 없는 페이지에서 나온 것이라 검토 플래그 없이 그대로 사용.
