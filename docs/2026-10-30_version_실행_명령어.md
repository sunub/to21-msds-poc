# version별 실행 명령어 모음

`backend/` 디렉터리 기준으로 실행한다(`cd backend` 먼저). 각 명령은 방법 정리 문서(`docs/2026-10-29_version1-9_방법정리.md`, `docs/2026-10-30_version1-12_전체_방법정리.md` 등)와 1:1로 대응한다.

## version1 — PDF 텍스트 + 이미지 렌더링 (OCR 별도 파일)

```bash
uv run python scripts/preprocess.py --purpose 개발          # 개발용 10건
uv run python scripts/preprocess.py --docs T21-S016 T21-025  # 특정 문서만
uv run python scripts/preprocess.py --all --force            # 전체 재실행
```

텍스트층이 나쁜 페이지를 별도 OCR 파일로 보강(`p001_ocr.txt`):

```bash
uv run python scripts/ocr_paddle.py --docs T21-002 T21-S003
uv run python scripts/ocr_paddle.py --all
```

(C(전처리)/C_v0.2로 B에게 전달한 것과 같은 구조로 만들려면 추가로)

```bash
uv run python scripts/write_metadata.py       # metadata.json 생성 (인자 없음)
uv run python scripts/build_combined_md.py    # combined_v2.md 생성
```

## version2 — PDF 텍스트 + PaddleOCR 하이브리드 (기준 방법)

```bash
uv run python scripts/ocr_batch_version2.py          # 기본값(output_version="version2")으로 전체 실행
```
스크립트 자체엔 CLI 인자가 없고 `main()` 함수 인자(`output_version`, `pipe_rows`, `force`, `selected_doc_id`, `line_numbers`)를 코드에서 직접 바꿔 호출해야 한다.

## version3 — Qwen3-VL-4B 대조 전사 + 그림문자 판독

```bash
uv run python scripts/ocr_batch_version3.py
```
마찬가지로 CLI 인자 없음(`main()`을 코드에서 직접 호출하는 구조).

## version4 — C 역할 후처리 (섹션 분할 + 코드 추출 + 표 묶기)

```bash
uv run python scripts/run_c_preprocess.py --doc-id T21-025
uv run python scripts/run_c_preprocess.py --all
```
옵션: `--input-root`(기본 `data/pages/version2`), `--output-root`(기본 `data/pages/version4`), `--analysis-root`(기본 `data/pages/version4_analysis`)

## version5 — C→B 전달 규격 포장 (version4 기반)

```bash

uv run python scripts/build_c_to_b_contract.py --all
```
옵션: `--source-root`(기본 `data/pages/version4`), `--output-root`(기본 `data/pages/version5`), `--sections-root`, `--codes-root`

## version6 — 재OCR(묶기+줄번호) + 재포장

```bash
# 1) 재OCR (결과: data/pages/version6_ocr)
uv run python scripts/ocr_batch_version6.py --doc-id T21-025
uv run python scripts/ocr_batch_version6.py --force   # 전체

# 2) 포장 (결과: data/pages/sections/codes version6)
uv run python scripts/build_c_to_b_contract.py --source-root ../data/pages/version6_ocr \
  --output-root ../data/pages/version6 \
  --sections-root ../data/sections/version6 \
  --codes-root ../data/codes/version6 --all
```

## 공통 참고

- `--doc-id`는 `data/manifest.csv`의 `doc_id` 컬럼 값(예: `T21-025`, `T21-S016`)을 쓴다.
- `--force`가 없으면 이미 결과가 있는 문서는 건너뛴다(재실행하려면 꼭 붙일 것).
- version11~13은 GPU(CUDA)가 필요하고, 처음 실행 시 `LD_LIBRARY_PATH`를 맞추기 위해 스크립트가 자기 자신을 한 번 재실행한다(정상 동작, `os.execv`).
