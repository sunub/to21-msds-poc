# `data/pages/b한테 준거/` — 각 폴더의 실제 생성 코드 확인 (재확인)

B에게 전달한 폴더(`data/pages/b한테 준거/`)를 다시 열어서 현재 구조 기준으로 각 폴더가 어떤 `.py`로 만들어졌는지 확인했다. (이전 확인 이후 폴더 구성이 바뀌어서 다시 정리함)

## 현재 폴더 구조

```
b한테 준거/
├── C_v0.2/
│   └── C(전처리)/        ← manifest.csv + pages/<doc_id>/
├── C_v0.3/
│   └── version2/         ← README.md + <doc_id>/
├── version3/              ← <doc_id>/ + 그림문자 판독 문서 + summary.json
└── version9/
    └── version9/          ← <doc_id>/ (한 겹 중첩)
```

## 결과

| 경로 | 만든 코드 | 확인 근거 |
|---|---|---|
| `C_v0.2/C(전처리)` | `preprocess.py`+`render.py`(p\*.png/p\*.txt) + `ocr_paddle.py`(p\*_ocr.txt) + `write_metadata.py`(metadata.json) + `build_combined_md.py`(combined_v2.md) — **4개 스크립트 조합** | `metadata.json`의 `schema_version: "TO21-MSDS-EXT v0.5"` 필드가 `write_metadata.py` 16번째 줄 코드와 정확히 일치, `combined_v2.md` 파일명이 `build_combined_md.py`의 출력 경로와 일치 |
| `C_v0.3/version2` | `backend/scripts/ocr_batch_version2.py` | `README.md`가 이 스크립트의 처리방식(PDF텍스트+PaddleOCR)을 그대로 설명 |
| `version3` | `backend/scripts/ocr_batch_version3.py` | 그림문자 판독 문서 포함, `config.json`에 `"model": "Qwen/Qwen3-VL-4B-Instruct"` |
| `version9/version9` | `backend/scripts/ocr_batch_version8.py --output-version version9` | `config.json`에 `"device": "gpu"`, `"models": [...]` 필드 — 이번 세션에 돌린 최신 코드로 생성된 것 확인 |

지난 확인 때는 "C_v0.3"이 `C(전처리)` 폴더를 담고 있었는데, 지금은 `C_v0.2`로 번호가 바뀌고 `C_v0.3`은 `version2` 결과를 담고 있다 — **직접 폴더를 재구성하신 것으로 보임.** 즉 번호(C_v0.2 / C_v0.3)는 드라이브 공유용 라벨일 뿐이고, 실제 만든 코드는 내용물(파일 종류/필드)로 확인해야 정확하다.

## "version10" 번호에 대해 (과거 기록 — 지금은 해소됨)

> ⚠️ 아래는 **그 시점에 있었던 사건의 기록**이다. 지금은 코드 번호를 공백 없이 재정리해서 `version10`이 실제로 Docling(GPU) 추출을 가리키도록 확정했다(아래 "번호 재정리" 참고). 과거에 "version10"이라고 구두로 불렀던 것은 **version3**을 가리켰다는 뜻이고, 더 이상 그렇게 부르지 않는다.

`data/pages/b한테 준거/` **로컬 폴더**에는 "version10"이라는 이름이 없었다.

다만 **B와 공유한 클라우드 드라이브 폴더에는 실제로 `version10.zip` 파일이 존재했다.** 로컬의 `data/pages/version10/`을 열어 확인한 결과(`config.json`의 `"version": "version3"` 필드) 이 `version10.zip`은 **version3 결과를 압축해서 이름만 version10으로 올린 것**이었다 — 구두 설명이 아니라 실제로 그렇게 이름 붙여서 전달된 파일이었다. 이 사본(`data/pages/version10`)은 번호 재정리 과정에서 version3과 완전히 동일함을 재확인하고 삭제했다.

## B에게 전달할 매핑 (이번 확인 기준)

- version2 (`C_v0.3/version2`로 드린 것) → PDF 텍스트 + PaddleOCR 추출
- version3 (`version3.zip`으로 드린 것, 예전에 "version10"이라고 말씀드렸던 것도 이거예요) → Qwen3-VL-4B 대조 전사 + 그림문자(GHS) 판독
- version9 (`version9.zip`) → version2 방식에 표 묶기(`|`)+줄번호 추가해서 20개 문서 전체 재추출
- version1 (`C_v0.2.zip`/`C(전처리)`으로 드린 것, **사실 version1과 동일** + metadata.json/combined_v2.md 추가) → PDF 텍스트/이미지 렌더링 + 별도 OCR 파일
- (앞으로 공유 예정) version10 → Docling(GPU, TableFormer) 단독 재추출
- (앞으로 공유 예정) version11 → version9 + Docling 표 결합(하이브리드)
