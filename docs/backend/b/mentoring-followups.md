# 멘토링 전에 우리가 정한 것

2026-11-03 작성. 기업 자료가 무조건 정답은 아니므로, 답을 기다리지 않고 근거를 찾아 직접 정했다. 코드에 반영됐고 `ENGINE_VERSION`을 0.4.0으로 올렸다. 멘토링에서는 "이렇게 정했는데 다른 의견이 있는가"로 확인한다. 답이 다르면 "바꿀 곳"을 고치고 버전을 올린 뒤 실버를 비교한다.

**판단 순서:** 법령 원문 > 설계서 > TO21 시험 패키지·지식DB. 법령에 답이 없으면 실제 MSDS 기재 관행을 보고, 근거 없이 MSDS를 틀렸다고 하지 않는 쪽으로 정한다.

**근거 자료:**
- 법령: 법제처 저장본을 새 검증자가 다시 받아 대조하고, 핵심 문구는 저장본에서 직접 찾았다. 저장소에는 넣지 않았다. 고시는 `~/to21-msds-poc/refs/`에 있다.
- 실제 MSDS: `~/to21-msds-poc/data/msds`의 한글 MSDS 3,435건을 글자만 뽑아 간이 정규식으로 셌다. 추출 모델을 쓰지 않았으므로 비율은 대략이다.

질문지 원본은 우진의 로컬 파일이라 이 저장소에 없다. Q 번호는 작업 기록에 적힌 것만 옮겼다.

## TO21 패키지와 달라지는 곳

패키지가 틀렸다고 단정하지 않는다. 멘토링에서 알려 주고 의견을 듣는다.

| 항목 | 패키지 | 우리 |
|---|---|---|
| 경구 구분 5 (P02·P03·P04) | 5 | 분류안됨 + 참고 |
| 발암성 (P02·P04) | 출처 단위 | 항목 단위 |
| 흡인 (P03) | 성분 합 10%만 | 동점도 포함 |
| 부등호 숫자 칸 | `=` | 문장 부호 |
| 범위 숫자 칸 | 상한 | 최솟값 |

## 그래도 사람 판단이 남는 것

- **제4류 혼합물의 공식 해석:** 법제처 해석례와 부처 해석을 찾았으나 없다. 에탄올 59% 수용액은 "알코올류"에서는 빠지지만 인화점 품명까지 없어지는지 원문만으로는 알 수 없고, 실제 MSDS는 비위험물로 적는다. 그래서 규제 누락으로 단정하지 않고 경계로 둔다.
- **자료 없는 성분이 많은 급성독성(공식 2)의 과대분류:** 설계서 공식이라 유지한다. 빈칸 원칙(3번)과 온도 차가 있다.
- **숫자 칸이 없는 `<` 문장:** D-12대로 계산에서 뺀다.
