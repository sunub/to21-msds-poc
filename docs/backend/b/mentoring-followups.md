## 받은 뒤 할 일

1. 답을 위 표에 적는다.
2. 값이 바뀌는 항목을 고치고, 엔진 버전(`ENGINE_VERSION`)을 올린다. 올리지 않으면 옛 판정을 재사용한다.
3. 실버 전체를 수정 전과 비교해 바뀐 줄을 확인한다.
4. `decisions.md`에 결정을 남기고 우진에게 공유한다.
