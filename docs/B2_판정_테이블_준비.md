# B2 판정 연결 기준

B2 판정 테이블과 서비스는 B 담당자의 `b2_001`·`judge.judgment` 구현을 기준으로 합니다. 해당 코드가 공유되면 B의 마이그레이션과 시험 안내에 따라 설치합니다. A 브랜치에서 별도로 제안했던 B2 테이블 SQL 세 개는 제거했으며, A 설치 실행기는 `judge` 스키마·테이블·권한을 생성하거나 관리하지 않습니다.

[팀 Docker·DB 구축 안내](../deploy/htodb/TEAM_SETUP.md)는 HTODB, A의 `extract` 테이블, A 적용 이력과 넘김 읽기 권한을 준비합니다. B는 `extract.handoff.payload_json`을 계약에 따라 읽으며, 넘김 식별자는 `(job_id, handoff_seq)`입니다. 이 단계는 B2 설치 전후 모두 실행할 수 있고, B의 독립적인 테이블 변경은 A의 적용 이력 검사 대상에 포함되지 않습니다.

이전 B2 SQL과 함께 A 설치를 마친 DB는 신규 설치 절차를 다시 적용하지 않습니다. 실행기는 기존 이력·체크섬 차이를 감지하면 중단하며 자동으로 테이블이나 이력을 변경하지 않습니다. 기존 데이터와 이력을 보존하고 A·B 담당자와 별도 전환 절차를 정합니다.
