오늘 수정한 버그: 표 공백 문제

증상: 모델(B) 쪽에서 표 안 공백 차이로 문제가 생긴다고 보고됨.

원인: c_pipeline.py의 SECTION_TITLES가 1~16항마다 한국어 표제 1개 + 영어 표제 1개만 하드코딩돼 있었음. 반면 to21/v0.6 사전에는 항목별로 공백·가운뎃점·표기가 다른 변형이 최대 7개까지 등록돼 있고, 사전 자체 note에 다음과 같이 적혀 있었음:

비교 시 공백·구두점·가운뎃점 제거 후 일치 검사. 사전에 없는 표기는 extras로 보내고 변경요청 대장에 등록.

즉 사전이 이미 있는데도 코드에서 안 쓰고 있어서, 사전에 등록된 변형과 다르게 쓰인 문서(예: "화학제품과 제조회사 정보")는 항목 분할이 실패할 수 있었음.

수정: _load_section_titles()를 추가해 to21/v0.6 사전의 sections를 런타임에 읽어 SECTION_TITLES를 구성하도록 변경. 사전을 못 읽으면 영어 표제 1개로 폴백.

검증: 항목 2(유해성·위험성)에 변형 8개가 로드되는 것, "화학제품과 제조회사 정보" 같은 변형 표기도 항목 1로 정상 매칭되는 것을 직접 실행해 확인.
