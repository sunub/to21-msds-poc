# 15항 판정은 성분 함량과 규제 기준 농도로 기대 해당 여부를 정해 공급사와 비교한다

4단계(15항 국내 법적 규제 판정, `backend/src/msds/compliance/sec15.py`의 `compare_sec15`)는 공급사가 15항에 적은 규제 해당 여부가 맞는지 판정한다. 3단계와 마찬가지로 지식DB와 설계서 v0.2가 없어, `knowledge.get_regulation`의 임시 형태를 약속으로 가정해 만들었다. 지식 응답을 가정하는 방식과 "provider에서 맞춘다"는 대응 원칙은 docs/adr/0003을 그대로 따른다. 이 문서는 15항에서 새로 정한 것만 적는다.

## 정한 것

판정 규칙은 2026-10-27 팀 결정이다. 규칙 목록은 `sec15.py` 상단에 있다.

- **비교 단위는 (성분, law, item_code)다.** 성분은 15항 행의 `comp_ref`(성분 순번)로 잇는다.
- **해외 규제(law `INTL`)는 판정하지 않는다.** 2차는 국내 법적 규제를 본다(D 가이드). 결과에도 남기지 않는다.
- **기대 해당 여부는 함량과 기준 농도로 계산한다.** 함량 하한과 상한으로 두 번 판단해 둘 다 기준 이상이면 해당, 둘 다 미만이면 비해당, 갈리면 **경계**다. 기준 농도가 없는 규제는 함량과 관계없이 해당이다.
- **기대가 해당인데 공급사가 비해당·자료없음·미기재로 적었거나 행을 빠뜨렸으면 불일치다.**
- **지식에 그 규제 행이 없으면, 공급사가 비해당이면 일치다.** 지식이 있다는 전제에서 규제 목록에 없는 물질은 비해당으로 본다. 공급사가 해당이라고 적었으면 근거부족이다.
- **혼합물 전체 행(`comp_ref` `MIX`)은 근거부족이다.** 판정 대상에서 빼지 않되, 성분 CAS로 조회하는 지금의 약속으로는 판단할 수 없다.

질문 범위 밖이라 구현자가 정한 것:

- 기대가 비해당인데 공급사가 해당으로 적었으면 불일치다. 공급사가 적지 않았거나 자료없음·미기재면 일치다(해당하지 않는 규제를 적지 않은 것은 모순이 아니다).
- 지식에 행이 없을 때 자료없음·미기재도 비해당과 같이 일치로 본다.
- 같은 (성분, 법령, 항목)에 기준 행이 여러 개면 하나라도 해당이면 해당, 아니면 하나라도 경계면 경계로 합친다.

## 가정한 약속 (0003의 A1~A7에 더해)

| # | 가정 | 쓰는 곳 |
|---|---|---|
| B1 | `get_regulation(cas)`의 `rows`는 `law`, `item_code`, `threshold_op`, `threshold_value`, `threshold_unit`, `source`를 가진다. 코드는 TO21 스키마의 C6 법령·항목 코드다 | 비교 키, 기대 해당 여부 |
| B2 | `threshold_op`는 `>=`(이상) 또는 `>`(초과)다. 비어 있으면 `>=`로 본다 | 기준 비교 |
| B3 | 기준 농도와 성분 함량의 단위는 %다. 다르면 근거부족으로 둔다(단위 변환은 PoC 범위 밖) | 기준 비교 |
| B4 | 기준 농도가 없는 행(`threshold_value` None)은 "함유하면 해당"이다 | 기대 해당 여부 |
| B5 | 시행일(`valid_from`)이 기준일보다 늦은 규제는 provider가 걸러 준다(0003 A7과 같음) | 판정 코드는 기준일을 넘기기만 함 |
| B6 | 성분 함량은 TO21 숫자 묶음(Q)이다. 하한이 없으면 0, 상한이 없으면 100까지 가능한 것으로 보고, `미만`(<)·`초과`(>) 끝은 그 값을 포함하지 않는다 | 하한·상한 두 번 판단 |

## 확인하지 못한 것 (한계)

- **실제 지식DB로 돌려 보지 않았다.** 시험의 규제 기준은 시험 안에서 직접 넣은 값이다. 25번 황산을 빈 지식(`EmptyProvider`)으로 돌려 실제 문서 형태에서 오류 없이 36행(52행 중 INTL 16행 제외)이 모두 근거부족으로 나오는 것까지만 확인했다.
- **공급사가 적은 기준 농도(`threshold`)와 지식의 기준 농도는 비교하지 않는다.** 해당 여부만 판정한다. 공급사가 기준 농도를 잘못 옮겨 적은 경우는 잡지 못한다.
- **세부 구분(`sub_class`, 예: 특별관리물질)과 수량 기준(`qty`, 예: 사고대비물질 지정수량)은 판정하지 않는다.**
- **혼합물 전체에 적용되는 규제는 판정하지 못한다.** 고시 제11조⑪은 혼합물 전체로서 적용되는 규제를 기재하게 하지만, 이를 판단할 지식 형태가 아직 없다.
- **판정은 국내 규제만 한다.** 해외 규제 행은 결과에 나오지 않는다.

## 실제 지식DB가 약속과 다를 때

대응 원칙(provider에서 맞추고, 판정 규칙 변경은 팀 결정, 변환에는 출처)은 0003과 같다.

| # | 다를 때의 모습 | 대응 | 판정 규칙 변경 |
|---|---|---|---|
| B1 | 법령·항목이 TO21 C6 코드가 아니다(법령 이름, 고시 번호 등) | provider에 변환표를 둔다. 변환되지 않는 항목은 목록으로 F에게 넘긴다 | 없음 |
| B2 | 기준이 "이상"·"초과" 외의 형태다(범위, "미만"이면 해당 등) | 형태를 모아 F에게 넘기고, 판정 규칙으로 정해지면 `_expected`와 시험을 함께 고친다 | 있음 |
| B3 | 기준 농도가 %가 아니다(ppm, 지정수량 kg 등) | %로 바꿀 근거가 있으면 provider에서 바꾸고, 없으면 그대로 두어 근거부족이 나오게 한다. 수량 기준은 이 판정의 범위가 아니다 | 없음 |
| B4 | "기준 농도 없음"이 "함유하면 해당"이 아니라 "기준 미상"을 뜻한다 | provider에서 두 경우를 나눠 주고, "기준 미상"은 근거부족이 나오게 판정 규칙을 고친다 | 있음 |
| B5 | 시행일이 없다 | 0003 A7과 같이 한계를 남기고 구버전 MSDS 판정은 "참고"로 보고한다 | 없음 |
| B6 | 지식에 혼합물 전체 규제 기준이 있다 | `MIX` 행 판정을 추가할 수 있다. 판정 규칙 변경이므로 팀 결정을 받는다 | 있음 |
| 기타 | 지식DB에 "비해당 확인" 기록이 따로 있다 | 지식에 행이 없을 때 일치로 보는 지금 규칙을, 비해당 기록이 있을 때만 일치로 바꿀지 팀에서 정한다 | 있음 |

지식DB가 왔을 때의 확인 순서는 0003과 같다. 15항에서는 25번 황산의 15항 행이 좋은 대조 자료다. 지식DB의 황산(7664-93-9) 규제 행으로 돌려 "공급사 15항과 대부분 일치하는가"를 먼저 본다. 25번은 TO21 정답 예제라 공급사 기재가 원문 그대로 정확히 옮겨져 있다.
