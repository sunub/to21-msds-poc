# data/pages/* 전체 폴더 — 어떤 코드가 만들었고 서로 어떻게 엮여있는지

> ⚠️ **번호 주의**: 이 문서는 2026-10-30 작성 당시 번호 기준이다. 이후 공백(version10)을 메우도록 재정리해서 **이 문서의 "version11"은 지금의 version10(Docling 단독)**, **이 문서의 "version12"는 지금의 version11(하이브리드)**을 가리킨다. 최신 번호는 `docs/2026-10-29_version10_방법정리.md`, `docs/2026-10-29_version11_방법정리.md`, `docs/2026-10-30_b한테_준거_생성코드_확인.md`의 "번호 재정리" 항목 참고.

커밋 범위를 정하기 위해 `data/pages/` 아래 **현재 존재하는 모든 폴더**를 열어서 실제 생성 코드를 확인했다.

> **먼저 알아야 할 것**: `.gitignore`에 `data/pages/*`가 전부 제외돼 있다(D-47 규칙, `.gitkeep`만 추적). 즉 **아래 산출물 폴더 자체는 어차피 커밋 대상이 아니다.** 커밋 여부를 판단해야 하는 건 이 폴더들을 만든 **코드 파일**(`backend/scripts/*.py`, `backend/src/...`)이다. 그래서 이 문서는 "어떤 코드가 아직 안 커밋됐는지"를 가리기 위한 자료다.

## 정정: version4의 실제 생성 코드

이전에 만든 `2026-10-29_version1-9_방법정리.md`에서 version4를 `ocr_batch_version4.py`가 만들었다고 적었는데, 디스크의 실제 `data/pages/version4/*/config.json`을 열어보니 필드 구성(`ocr_base`, `postprocess`, `uses_qwen` 등)이 `ocr_batch_version2.main()`이 쓰는 필드(`device`, `models`)와 다르고, **`run_c_preprocess.py`가 `config.update()`로 덧붙이는 필드와 정확히 일치**했다. 즉:

- `ocr_batch_version4.py`: version2를 `pipe_rows=True`로 고정 재실행하는 **코드는 존재**하지만, 디스크의 현재 `version4` 폴더 내용은 이 스크립트가 아니라 **`run_c_preprocess.py`(C-역할 후처리: 섹션분할+다중MSDS+코드추출+표 행묶기)가 만든 것**.
- `run_c_preprocess.py`는 입력을 `version2`에서 읽고, `msds.preprocess.c_pipeline.process_document()`로 분석한 뒤 `version4`(B 전달용, 표만 `|`로 묶인 txt)와 `version4_analysis`(sections.json/codes.json/table_rows.json/diagnostics.json/report.md 등 분석 근거)를 함께 만든다.

## 의존 관계 (누가 누구 결과를 입력으로 쓰는지)

```
version1 ──(이미지 재사용)──┐
                          │
version2(OCR) ──────────► run_c_preprocess.py ──► version4 + version4_analysis
                          │                                 │
                          │                                 ▼(좌표 재사용)
                          │                              version5 (포장)
                          │
version6_ocr(OCR) ───────► build_c_to_b_contract.py ──► version6 (포장)

version2(OCR) ──(재실행, 옵션 동일)──► version7

ocr_batch_version2.main() 재사용, pipe_rows+line_numbers 고정
  └─ version8.py ──► version8 (일부 문서), version9 (전체 20건)

version3(Qwen) ──(사용자가 사본을 만들어 번호를 맞춤)──► version10

ocr_batch_docling.py (Docling GPU, 처음부터 새로 추출) ──► version11

version9 OCR 로직 재사용 + Docling 표 그리드만 선택적으로 교체 ──► version12
  (Docling 표 감지는 version11을 만들 때 쓴 것과 같은 TableFormer 파이프라인)
```

## 확인됨 (디스크 vs 현재 스크립트 비교로 검증한 것)

- `version2/*/config.json`에 `device`/`models` 필드가 **없음** → 지금 리포에 있는 `ocr_batch_version2.py`(이 필드들을 쓰는 버전)보다 **더 오래된 코드**로 생성된 산출물. version1~3, version6_ocr도 마찬가지로 이번 세션보다 전에 만들어진 것으로 보임.
- `version7/8/9/10(test)/11/12/*/config.json`에는 `device`/`models` 필드가 **있음** → 지금 리포 코드로 실행된 것이 맞음(이번 세션에서 직접 재현/신규 실행).
