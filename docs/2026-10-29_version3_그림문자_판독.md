# version3 그림문자(GHS 픽토그램) 판독 방법

`ocr_batch_version3.py`는 본문 전사 외에 GHS 그림문자·신호어를 따로 판독하는 전용 로직을 갖고 있다.

## 어디에 있나

- 코드: `backend/scripts/ocr_batch_version3.py`
- 프롬프트: `PICTOGRAM_PROMPT` (29~32행)
- 적용 로직: `main()` 내부 `needs_pictogram` 분기 (59, 74~81행)

## 동작 순서

1. **대상 페이지 판별** (59행)
   - 해당 페이지의 PDF 텍스트(version1)와 PDF+Paddle 텍스트(version2)를 합친 참고 텍스트(`reference`)에 `"그림문자"` 또는 `"pictogram"`이라는 단어가 있는지 확인한다.
   - 있으면 `needs_pictogram = True` → 이 페이지만 그림문자 전용 판독을 추가로 수행한다. (보통 2. 유해성·위험성 항목이 있는 페이지)

2. **본문 전사 1차 반영** (`PROMPT`, 16행)
   - 메인 전사 프롬프트에도 "그림문자는 보이는 순서대로 `[그림문자 GHSxx]`로 기록하고 신호어 값을 누락하지 마라"는 지시가 포함돼 있어, Qwen이 본문을 옮겨 적을 때 그림문자를 1차로 함께 기록한다.

3. **그림문자 전용 판독** (`PICTOGRAM_PROMPT`, 74~79행)
   - `needs_pictogram`인 페이지에 대해 같은 페이지 이미지를 다시 Qwen3-VL-4B에 넣고, 이번엔 그림문자·신호어만 판독하도록 별도 호출한다.
   - 프롬프트가 요구하는 것:
     - 그림문자 **개수와 왼쪽부터의 순서**를 원본 이미지로 직접 확인
     - GHS 코드 대응표 적용:
       | 모양 | 코드 |
       |---|---|
       | 폭발 | GHS01 |
       | 불꽃 | GHS02 |
       | 원 위의 불꽃 | GHS03 |
       | 가스 용기 | GHS04 |
       | 부식 | GHS05 |
       | 해골 | GHS06 |
       | 느낌표 | GHS07 |
       | 사람 가슴 별모양(건강유해성) | GHS08 |
       | 죽은 나무와 물고기(환경유해성) | GHS09 |
     - 그림문자가 없으면 `[그림문자 0개]`
     - 출력 형식을 다음 두 줄로 고정:
       ```
       [그림문자 N개: GHSxx, GHSxx]
       [신호어: 위험/경고/없음]
       ```
   - 결과는 `candidates/{stem}_pictograms.txt`로 저장.

4. **최종 텍스트에 병합** (80~82행)
   - `needs_pictogram`인 페이지는 본문 전사 텍스트 뒤에 아래 섹션을 그대로 덧붙여 최종 `{stem}.txt`를 만든다.
     ```
     [그림문자·신호어 전용 판독]
     [그림문자 N개: GHSxx, GHSxx]
     [신호어: 위험/경고/없음]
     ```

## 요약

- 그림문자 판독은 **모든 페이지에서 하는 게 아니라**, 참고 텍스트에 "그림문자"/"pictogram" 단어가 있는 페이지(주로 2항)에서만 추가로 수행된다.
- 같은 이미지를 두 번 Qwen에 넣는다: 1차는 본문 전체 전사(그림문자 표기 포함), 2차는 그림문자·신호어만 집중 판독해서 신뢰도를 보강.
- 최종 산출물에는 본문 전사 중 1차로 들어간 `[그림문자 GHSxx]` 표기와, 2차 전용 판독 결과 `[그림문자·신호어 전용 판독]` 섹션이 둘 다 들어있다.
