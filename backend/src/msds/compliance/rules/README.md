# 규칙표 (역할 E)

| 파일 | 내용 | 쓰는 곳 |
|---|---|---|
| hazard_label_map.csv | H코드 ↔ 유해성 분류, 분류 ↔ 그림문자·신호어 | 1차 검증기 V05·V06 확장, 2차 표시 요소 검증 |
| sec15_rules.csv | 15항 법령 × 규제 항목 × 기준 농도 | 2차 15항 판정 |

작성 원칙
- 근거: 고용노동부 고시 「화학물질의 분류·표시 및 물질안전보건자료에 관한 기준」 별표(최신 고시 번호 확인 필요).
- 행마다 `source`에 출처(고시 번호, 별표, 쪽)를 적는다. 출처 없는 행은 넣지 않는다.
- 코드는 TO21 명세서 코드표(5-1 유해성분류, 5-2 그림문자, 5-6 법규제)의 코드를 쓴다.
- 같은 H코드가 여러 분류에 대응하면 행을 나눈다.
- 1주차 완료 기준: 매핑표로 정답 예제(25번 황산)의 H코드·그림문자·신호어 조합을 설명할 수 있다.
