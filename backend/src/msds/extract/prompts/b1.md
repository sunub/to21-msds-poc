# 이번 묶음: ① 머리글·1·2·3항
읽을 곳: 머리글(관리정보), 1항 화학제품과 회사, 2항 유해성·위험성, 3항 구성성분
뽑을 칸: doc.language, doc.msds_count, msds[].meta, msds[].product, msds[].companies, msds[].hazard, msds[].composition, msds[].components

## 묶음 안내
- 한 파일에 MSDS가 여러 건이면(키트, A/B제 등) msds를 건마다 나누고 meta.page_start / page_end에 쪽 범위를 적는다(R16). 대부분은 1건이다.
- 관리정보: MSDS 번호(제출번호)와 회사 내부 문서번호를 구분한다. 회사 내부 번호는 msds_no가 아니다. 날짜는 R01.
- 회사(companies): 역할(제조자·수입자·공급자 등)마다 한 항목. 전화·팩스·이메일은 contacts로 나누고, 긴급 연락처는 type="긴급". 전화번호는 R12.
- 유해성 분류(hazard.classes): 분류마다 한 항목. 구분(category)은 '구분' 글자를 뺀다(R07). 급성독성(흡입) 등 노출 형태가 적혀 있으면 route_form에 원문대로(가스 / 증기 / 분진·미스트).
- 신호어·그림문자: 문서에 보이는 것만. 그림문자는 이미지에서 실제로 보이는 그림의 코드를 적고 detection="이미지판독". 그림이 보이지 않으면 넣지 않는다.
- H·P 코드: R05, R21. P코드의 type은 첫 자리로 정한다(P1 일반, P2 예방, P3 대응, P4 저장, P5 폐기).
- 성분(components): 성분표의 행마다 한 항목, seq는 1부터. CAS와 KE 번호를 나눈다(R02, R03). 함유량은 Q로 나눈다(R04, R06, R19). 원문은 raw에 그대로 둔다. 영업비밀은 R13·R23, 하위 성분은 R22, 가려진 값은 R20.

## [규칙] (TO21 명세서 3_정규화규칙)
- R01 날짜: YYYY-MM-DD로 통일. 일이 없으면 YYYY-MM. 원문 예: 2024.05.14 / 2024-5-14 / 2024년 5월 14일 / 24.05.14 → 저장 예: 2024-05-14 (두 자리 연도는 2000년대로 해석)
- R02 CAS 번호: 공백·전각 하이픈 제거 후 형식 검사, 체크디지트 검증. 실패 시 값 유지+confidence 낮춤. 원문 예: 7664 - 93 - 9 / 7664‐93‐9 → 저장 예: 7664-93-9 (체크디지트: 뒤에서부터 자릿수×위치 합 mod 10)
- R03 KE 번호: 'KE-' + 5자리. CAS와 한 칸에 함께 있으면 분리. 원문 예: 108-10-1 / KE-24725 → 저장 예: cas_no=108-10-1, ke_no=KE-24725
- R04 수치 분해(Q): 원문은 raw에 보존하고 부등호·값·단위를 각각 분리. '이상'=>=, '초과'=>, '이하'=<=, '미만'=<. 범위는 lower/upper, 단일값은 value. 원문 예: 20 ~ 30 % / <1 % / 99.92 / ≥ 95 / 10% 이상 / 1 미만 / 약 23 ℃ → 저장 예: {lower_op:'>=',lower:20,upper_op:'<=',upper:30,unit:'%'} / {upper_op:'<',upper:1,unit:'%'} / {value:99.92} / {lower_op:'>=',lower:95} / {lower_op:'>=',lower:10,unit:'%'} / {upper_op:'<',upper:1} / {value:23,approx:true,unit:'C'} ('~'로 묶인 범위의 양 끝은 포함(>=, <=)으로 간주)
- R05 H/P 코드: 대문자, 공백 제거. 결합 코드는 '+'로 한 문자열 유지. P코드 유형은 첫 자리로 결정. 원문 예: H 302 + H 332 / p280 → 저장 예: H302+H332 / P280 (P1 일반·P2 예방·P3 대응·P4 저장·P5 폐기)
- R06 숫자: 천단위 콤마 제거, 지수 표기 허용, '약'·'approx.'는 approx=true로. 원문 소수 자릿수는 dp에 기록(2.0 → value 2, dp 1). 원문 예: 약 1,000 / 1.2E-3 / 2.0 → 저장 예: 1000(approx) / 0.0012 / 2(dp=1) (MSDS 재생성 시 '2.0' 그대로 출력하기 위함)
- R07 분류 구분: '구분', 'Category', 'Cat.' 글자 제거. 원문 예: 구분 1A / Category 2 → 저장 예: 1A / 2
- R11 목록 분리: 이명·동의어·용도는 ';' 또는 ',' 기준으로 배열 분리, 앞뒤 공백 제거. 단 괄호 안의 예시 목록은 쪼개지 않고 상위 항목과 함께 하나로 둠(정보 손실 방지). 원문 예: 메틸벤젠 ; 메틸벤졸 / 비료, 다양한 공정 보조제(pH조절제, 응집제 등) → 저장 예: ["메틸벤젠","메틸벤졸"] / ["비료","다양한 공정 보조제(pH조절제, 응집제 등)"]
- R12 전화번호: 숫자·하이픈·괄호·+만 남김. 여러 번호면 첫 번호, 나머지는 원문 유지. 원문 예: Tel) 052 240 7073 → 저장 예: 052-240-7073
- R13 영업비밀: '영업비밀', '대체자료', '대체명칭', 승인번호 표기가 있으면 trade_secret=true. 함유량 범위는 원문대로.
- R14 서술형 분해(STMT): 불릿(-, ○, ·, •, 1), 가))·줄 단위로 statements[]를 나눔. '키 : 값'은 key/value 분리, '[성분명] : 값'은 refs로 성분 연결. 쪽 머리글·바닥글 제거, 쪽을 넘는 문장은 이어붙임. 원문 예: - 회사명 : ㈜가나화학 / - [황산] : 해당없음 → 저장 예: {key:'회사명',value:'㈜가나화학'} / {refs:['1'],value:'해당없음'} (MSDS 재생성 시 seq 순서대로 다시 조립)
- R15 자료없음/해당없음: 두 표기를 구분해 status에 저장(고시 제11조제7항). 빈칸·'-'는 미기재로 처리. 원문 예: 자료없음 / 해당 없음 / - → 저장 예: 자료없음 / 해당없음 / 미기재
- R16 다중 MSDS 파일: 키트·여러 등급처럼 한 파일에 MSDS가 여러 개면 msds[]를 나누고 page_range를 기록.
- R17 원문 우선: 정규화로 의미가 바뀔 위험이 있으면 정규화하지 않고 raw만 채움. 추측 금지.
- R19 0값·개방범위: '0.00'은 value=0 + content_note(미검출/극미량), '0~10'은 lower 0 포함 범위, '≥ 99'처럼 한쪽만 있으면 그쪽만 채움. 원문 예: 0.00 / 0 ~ 10 / ≥ 99 → 저장 예: {value:0, note:미검출} / {lower_op:'>=',lower:0,upper_op:'<=',upper:10} / {lower_op:'>=',lower:99}
- R20 마스킹 값: '○○○', '***', 'XXX'처럼 가려진 값은 status=마스킹, 값은 null, raw는 원문 그대로. 원문 예: CAS : ○○○-○○-○ → 저장 예: cas_no=null, status=마스킹
- R21 H코드 변형: 접미 문자(H360FD, H361d)는 코드에 포함, 결합 코드는 '+'로 유지, '*'·'**' 각주 기호는 mark로 분리. EUH코드·구 EU R문구(R36/38)는 system으로 구분. 원문 예: H361d ** / R36/38 → 저장 예: code=H361d, mark=** / code=R36/38, system=R
- R22 혼합물 계층: 성분표에 상위 성분 아래 하위 성분이 들여쓰기·괄호로 묶여 있으면 하위 성분의 parent_seq에 상위 seq 기록. 원문 예: 천연가스 > 메탄, 에탄 → 저장 예: 메탄.parent_seq=1
- R23 대체자료 승인번호 위치: 승인번호·유효기간이 성분표 아래 한 번만 있으면 대체자료 표기 성분 모두에 같은 값을 넣음.

## [공통 구조] 숫자(Q)·측정 조건(COND)·서술 문장(STMT) (TO21 명세서 2_공통구조)
모든 수치는 Q, 측정조건은 COND, 서술형 문장은 STMT로 저장. '택1' = value 또는 lower/upper 중 하나.
Q — 수치 객체 — 모든 숫자 값(함유량·물성·노출기준·독성·규제 기준 등)
키 | 이름 | 타입 | 필수 | 분해 규칙 | 예시
raw | 원문 | string | 필수 | 분해 전 원문 그대로 | 약 1,000 ~ 2,000 mg/kg
approx | 근사 표기 | boolean | 선택 | '약','approx.','≈','정도' 있으면 true | true
value | 단일값 | number | 택1 | 하나의 값일 때. 범위면 null
lower_op | 하한 부등호 | enum | 택1 | > 또는 >= ('이상'=>=, '초과'=>) | >=
lower | 하한값 | number | 택1 | 1000
upper_op | 상한 부등호 | enum | 택1 | < 또는 <= ('이하'=<=, '미만'=<) | <=
upper | 상한값 | number | 택1 | 2000
unit | 단위 | string | 선택 | 정규화 기호(R08). 무단위면 null | mg/kg
dp | 소수 자릿수 | integer | 선택 | 원문 숫자의 소수점 아래 자릿수(최댓값). '2.0'은 숫자로 저장하면 2가 되므로 dp=1로 표기 형식을 보존 | 1
status | 상태 | enum | 필수 | 값있음/자료없음/해당없음/미기재/판독불가/마스킹 (C7) | 값있음
note | 부가 설명 | string | 선택 | 값·상태 뒤 괄호 설명 — '해당없음(불연성)'의 '불연성', '(미검출)' 등. 단위·조건이 아닌 것만 | 불연성
COND — 측정 조건 — 물성·독성 값에 붙는 괄호 속 조건
키 | 이름 | 타입 | 필수 | 분해 규칙 | 예시
temp | 온도 | number | 선택 | '(20℃)','@25 °C' → 20, 25 | 20
temp_unit | 온도 단위 | enum | 선택 | C / F / K | C
pressure | 압력 | number | 선택 | 101.3
pressure_unit | 압력 단위 | string | 선택 | kPa, mmHg, hPa, atm 등 | kPa
method | 방법 | string | 선택 | 밀폐식, 개방식, Closed cup, OECD TG 등 | 밀폐식
reference | 기준 물질 | string | 선택 | 비중 '물=1', 증기밀도 '공기=1' | 물=1
conc_value | 농도 | number | 선택 | '1% 수용액' 등의 조건 농도 | 1
conc_unit | 농도 단위 | string | 선택 | %
STMT — 서술 문장 — 서술형 항목을 문장/불릿 단위로 쪼갠 것
키 | 이름 | 타입 | 필수 | 분해 규칙 | 예시
seq | 순번 | integer | 필수 | 항목 안에서 1부터 — MSDS 재생성 시 순서 | 1
key | 키 | string | 선택 | '키 : 값' 형태면 콜론 앞(예: 회사명, 용도, 권고 용도). 없으면 null | 권고 용도
value | 값 | string | 필수 | 키가 있으면 콜론 뒤, 없으면 문장 전체 | 비료
refs | 성분 지정 | string[] | 선택 | '[황산] : …'처럼 성분을 지정한 문장이면 해당 comp_ref | ["1"]
cond | 조건 수치 | Q | 선택 | '노출농도 100 ppm 이하에서는 …'처럼 조건 숫자가 있는 문장이면 Q로 분리 | {upper_op:'<=',upper:100,unit:'ppm'}
std_code | 표준문구 코드 | string | 선택 | TO21 문구DB(또는 공인 표준문구) 매칭 코드. 매칭 전 null | PPE-RESP-012
match_score | 매칭 유사도 | number | 선택 | 0~1 | 0.92
text | 원문 | string | 필수 | 분해 전 원문 한 줄(검증용) | - 용도 : 비료
Q 분해 예시
원문(raw) | value | lower_op | lower | upper_op | upper | unit | 기타 분해 | 용도

99.92 | 99.92 | % | 단일값
10% 이상 함유한 황산 | >= | 10 | % | 15항 규제 기준
약 105 ~ 110 ℃ | >= | 105 | <= | 110 | C | approx=true | 끓는점
1.18 (20℃, 물=1) | 1.18 | COND: temp=20, temp_unit=C, reference=물=1 | 비중
> 0.375 mg/L (4hr, 랫드) | > | 0.375 | mg/L | duration_value=4, duration_unit=hr, species=랫드 | 흡입 LC50
200L | 200 | L | 위험물 지정수량
자료없음 | status=자료없음 | 값 없음
