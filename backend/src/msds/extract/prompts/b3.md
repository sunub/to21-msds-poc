# 이번 묶음: ③ 11·12항
읽을 곳: 11항 독성에 관한 정보, 12항 환경에 미치는 영향
뽑을 칸: msds[].toxicity, msds[].cmr, msds[].ecotox

## 묶음 안내
- 11항 독성(toxicity): 성분 × 독성 항목(endpoint) × 지표(LD50·LC50·ATE 등) × 시험 동물마다 한 행이다.
- 급성독성(경구·경피·흡입) 값은 필수 칸이다. 흡입은 노출 형태(physical_form: 가스 / 증기 / 분진·미스트)와 노출 시간(duration)을 원문대로 적는다.
- "자료없음"으로 적힌 항목도 행으로 남기고 status로 표시한다.
- 발암성·생식세포변이원성·생식독성의 기관별 분류는 cmr에 기관(agency)마다 한 행.
- 12항 생태독성(ecotox): 성분 × 항목 × 지표 × 생물종마다 한 행. 값은 q.
- comp_ref는 [성분 목록]의 번호, 제품 전체 값은 "MIX"(R10).

## [필드 정의] (TO21 명세서 1_항목정의)
형식: `경로` 이름 — 타입, 중요도. 형식·분해 규칙 [참조] 예(가상 값)
- `toxicity[].comp_ref` 대상 성분 — string, 중요. 성분 seq 또는 'MIX' [참조 R10, V11] 예: 1
- `toxicity[].endpoint` 독성 항목 — code, 중요. C5 [참조 C5] 예: TX_ORAL
- `toxicity[].descriptor` 지표 — enum, 중요. LD50 / LC50 / ATE / NOAEL / LOAEL / 결과기술 예: LD50
- `toxicity[].q` 값 — Q, 중요. Q 구조 [참조 R04]
- `toxicity[].species` 시험종 — string, 중요. Rat → 랫드 등 원문 유지 예: 랫드
- `toxicity[].sex` 성별 — enum, 일반. 수컷 / 암컷 / 혼합 / 미표기
- `toxicity[].duration_value` 노출 시간 — number, 중요. '4hr' → 4 예: 4
- `toxicity[].duration_unit` 노출 시간 단위 — enum, 중요. min / hr / day / week 예: hr
- `toxicity[].physical_form` 흡입 형태 — enum, 일반. 가스 / 증기 / 분진·미스트 예: 증기
- `toxicity[].exposure_type` 노출 형태 — string, 일반. 반복 경구 90일 등
- `toxicity[].converted` 환산값 — Q, 일반. 원문에 환산값이 병기된 경우(ppm ↔ mg/L 등) [참조 R04]
- `toxicity[].read_across_cas` 유사물질 참조 CAS — string, 일반. [참조 R02]
- `toxicity[].guideline` 시험 지침 — string, 일반. OECD TG 401 등 예: OECD TG 401
- `toxicity[].data_source` 자료 출처 — string, 일반. ECHA, NITE, IUCLID 등 괄호 속 출처 예: ECHA
- `toxicity[].classification` 분류 결과 — string, 일반. '구분4', '분류되지 않음' 등 예: 구분4
- `toxicity[].statements[]` 기타 서술 — STMT, 일반. 수치로 쪼갤 수 없는 문장
- `toxicity[].status` 행 상태 — enum, 중요. '[물] : 자료없음'처럼 값 없이 상태만 있는 행도 반드시 남김(MSDS 재생성용) [참조 C7, V16] 예: 값있음
- `cmr[].comp_ref` 대상 성분 — string, 중요. 성분 seq 또는 'MIX' [참조 R10, V11] 예: 1
- `cmr[].hazard` 유해성 — enum, 중요. 발암성 / 생식세포변이원성 / 생식독성 예: 발암성
- `cmr[].agency` 분류 기관·법령 — code, 중요. C8 [참조 C8] 예: IARC
- `cmr[].class` 분류 등급 — string, 중요. 'Group 1', '1A', 'A2' 등 기관 표기 그대로(공백 정리) 예: Group 1
- `cmr[].status` 상태 — enum, 중요. [참조 C7] 예: 값있음
- `cmr[].note` 조건·비고 — string, 일반. '(강무기산 미스트인 경우)' 같은 괄호 속 조건 예: 강무기산 미스트인 경우
- `ecotox[].comp_ref` 대상 성분 — string, 중요. 성분 seq 또는 'MIX' [참조 R10, V11] 예: 1
- `ecotox[].endpoint` 생태 항목 — code, 중요. C5 [참조 C5] 예: ECO_FISH
- `ecotox[].descriptor` 지표 — enum, 중요. LC50/EC50/ErC50/EC10/NOEC/BCF/logKow/Koc/분해율/BOD/COD/결과기술/기타 예: LC50
- `ecotox[].q` 값 — Q, 중요. Q 구조 [참조 R04]
- `ecotox[].species` 시험종 — string, 중요. 예: Lepomis macrochirus
- `ecotox[].duration_value` 노출 시간 — number, 중요. '96hr','28일' → 96, 28 예: 96
- `ecotox[].duration_unit` 노출 시간 단위 — enum, 중요. hr / day 예: hr
- `ecotox[].guideline` 시험 지침 — string, 일반. 예: OECD TG 203
- `ecotox[].data_source` 자료 출처 — string, 일반.
- `ecotox[].statements[]` 기타 서술 — STMT, 일반.
- `ecotox[].status` 행 상태 — enum, 중요. 값 없이 상태만 있는 행도 남김 [참조 C7, V16] 예: 값있음

## [규칙] (TO21 명세서 3_정규화규칙)
- R02 CAS 번호: 공백·전각 하이픈 제거 후 형식 검사, 체크디지트 검증. 실패 시 값 유지+confidence 낮춤. 원문 예: 7664 - 93 - 9 / 7664‐93‐9 → 저장 예: 7664-93-9 (체크디지트: 뒤에서부터 자릿수×위치 합 mod 10)
- R04 수치 분해(Q): 원문은 raw에 보존하고 부등호·값·단위를 각각 분리. '이상'=>=, '초과'=>, '이하'=<=, '미만'=<. 범위는 lower/upper, 단일값은 value. 원문 예: 20 ~ 30 % / <1 % / 99.92 / ≥ 95 / 10% 이상 / 1 미만 / 약 23 ℃ → 저장 예: {lower_op:'>=',lower:20,upper_op:'<=',upper:30,unit:'%'} / {upper_op:'<',upper:1,unit:'%'} / {value:99.92} / {lower_op:'>=',lower:95} / {lower_op:'>=',lower:10,unit:'%'} / {upper_op:'<',upper:1} / {value:23,approx:true,unit:'C'} ('~'로 묶인 범위의 양 끝은 포함(>=, <=)으로 간주)
- R06 숫자: 천단위 콤마 제거, 지수 표기 허용, '약'·'approx.'는 approx=true로. 원문 소수 자릿수는 dp에 기록(2.0 → value 2, dp 1). 원문 예: 약 1,000 / 1.2E-3 / 2.0 → 저장 예: 1000(approx) / 0.0012 / 2(dp=1) (MSDS 재생성 시 '2.0' 그대로 출력하기 위함)
- R08 단위: ㎥→m3, ℃→C, ㎎→mg 등 기호 통일. 단위 변환은 하지 않음(PoC 범위 밖). 원문 예: mg/㎥ / 23 ℃ → 저장 예: mg/m3 / 23 C
- R10 성분 참조(comp_ref): 8·11·12·15항 값이 특정 성분 것이면 components[].seq, 제품 전체면 'MIX'. CAS로 먼저 매칭, 없으면 이름. 원문 예: [황산] : TWA 0.2 mg/㎥ → 저장 예: comp_ref=1
- R15 자료없음/해당없음: 두 표기를 구분해 status에 저장(고시 제11조제7항). 빈칸·'-'는 미기재로 처리. 원문 예: 자료없음 / 해당 없음 / - → 저장 예: 자료없음 / 해당없음 / 미기재
- R17 원문 우선: 정규화로 의미가 바뀔 위험이 있으면 정규화하지 않고 raw만 채움. 추측 금지.

## [공통 구조] 숫자(Q)·측정 조건(COND)·서술 문장(STMT) (TO21 명세서 2_공통구조)
모든 수치는 Q, 측정조건은 COND, 서술형 문장은 STMT로 저장. '택1' = value 또는 lower/upper 중 하나.
Q — 수치 객체 — 모든 숫자 값(함유량·물성·노출기준·독성·규제 기준 등)
키 | 이름 | 타입 | 필수 | 분해 규칙 | 예시
raw | 원문 | string | 필수 | 분해 전 원문 그대로 | 약 1,000 ~ 2,000 mg/kg
approx | 근사 표기 | boolean | 선택 | '약','approx.','≈','정도' 있으면 true | true
value | 단일값 | number | 택1 | 하나의 값일 때. 범위면 null
lower_op | 하한 부등호 | enum | 택1 | > 또는 >= ('이상'=>=, '초과'=>) | >=
lower | 하한값 | number | 택1 | 1000
upper_op | 상한 부등호 | enum | 택1 | < 또는 <= ('이하'=<=, '미만'=<) | <=
upper | 상한값 | number | 택1 | 2000
unit | 단위 | string | 선택 | 정규화 기호(R08). 무단위면 null | mg/kg
dp | 소수 자릿수 | integer | 선택 | 원문 숫자의 소수점 아래 자릿수(최댓값). '2.0'은 숫자로 저장하면 2가 되므로 dp=1로 표기 형식을 보존 | 1
status | 상태 | enum | 필수 | 값있음/자료없음/해당없음/미기재/판독불가/마스킹 (C7) | 값있음
note | 부가 설명 | string | 선택 | 값·상태 뒤 괄호 설명 — '해당없음(불연성)'의 '불연성', '(미검출)' 등. 단위·조건이 아닌 것만 | 불연성
COND — 측정 조건 — 물성·독성 값에 붙는 괄호 속 조건
키 | 이름 | 타입 | 필수 | 분해 규칙 | 예시
temp | 온도 | number | 선택 | '(20℃)','@25 °C' → 20, 25 | 20
temp_unit | 온도 단위 | enum | 선택 | C / F / K | C
pressure | 압력 | number | 선택 | 101.3
pressure_unit | 압력 단위 | string | 선택 | kPa, mmHg, hPa, atm 등 | kPa
method | 방법 | string | 선택 | 밀폐식, 개방식, Closed cup, OECD TG 등 | 밀폐식
reference | 기준 물질 | string | 선택 | 비중 '물=1', 증기밀도 '공기=1' | 물=1
conc_value | 농도 | number | 선택 | '1% 수용액' 등의 조건 농도 | 1
conc_unit | 농도 단위 | string | 선택 | %
STMT — 서술 문장 — 서술형 항목을 문장/불릿 단위로 쪼갠 것
키 | 이름 | 타입 | 필수 | 분해 규칙 | 예시
seq | 순번 | integer | 필수 | 항목 안에서 1부터 — MSDS 재생성 시 순서 | 1
key | 키 | string | 선택 | '키 : 값' 형태면 콜론 앞(예: 회사명, 용도, 권고 용도). 없으면 null | 권고 용도
value | 값 | string | 필수 | 키가 있으면 콜론 뒤, 없으면 문장 전체 | 비료
refs | 성분 지정 | string[] | 선택 | '[황산] : …'처럼 성분을 지정한 문장이면 해당 comp_ref | ["1"]
cond | 조건 수치 | Q | 선택 | '노출농도 100 ppm 이하에서는 …'처럼 조건 숫자가 있는 문장이면 Q로 분리 | {upper_op:'<=',upper:100,unit:'ppm'}
std_code | 표준문구 코드 | string | 선택 | TO21 문구DB(또는 공인 표준문구) 매칭 코드. 매칭 전 null | PPE-RESP-012
match_score | 매칭 유사도 | number | 선택 | 0~1 | 0.92
text | 원문 | string | 필수 | 분해 전 원문 한 줄(검증용) | - 용도 : 비료
Q 분해 예시
원문(raw) | value | lower_op | lower | upper_op | upper | unit | 기타 분해 | 용도
20 ~ 30 % | >= | 20 | <= | 30 | % | 함유량 범위
<1 | < | 1 | % | 함유량 상한만
99.92 | 99.92 | % | 단일값
10% 이상 함유한 황산 | >= | 10 | % | 15항 규제 기준
약 105 ~ 110 ℃ | >= | 105 | <= | 110 | C | approx=true | 끓는점
1.18 (20℃, 물=1) | 1.18 | COND: temp=20, temp_unit=C, reference=물=1 | 비중
> 0.375 mg/L (4hr, 랫드) | > | 0.375 | mg/L | duration_value=4, duration_unit=hr, species=랫드 | 흡입 LC50
200L | 200 | L | 위험물 지정수량
자료없음 | status=자료없음 | 값 없음

### status
