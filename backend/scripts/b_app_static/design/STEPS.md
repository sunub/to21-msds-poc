G1은 11/2에 승인됐습니다. 지울 항목 D1·D2·D3, 서랍 배치표, 규칙 변경 11줄을 표대로 합니다. 메모는 "G1 승인 반영"에 있습니다.
조사 기준은 2026-11-02의 `b/app-steps`, 커밋 `386bfc5`입니다.
정본 승인 기록의 G0는 승인입니다. 메모는 “지금 step 0만 돌린다”입니다.

현재 코드에서 직접 접힘을 만드는 호출 위치는 37곳입니다. 화면별 내용 종류로 합치면 33종입니다.

코드 위치는 이 문서를 작성한 커밋 기준입니다.
`source.js` 등 JS 파일의 기준 폴더는 `backend/scripts/b_app_static/js/`입니다.
`b_app.py` 등 Python 파일의 기준 폴더는 `backend/scripts/`입니다.
이 문서의 ‘서랍’은 필요할 때 여는 자세히 영역입니다. 서랍 안에 접힘을 다시 넣지 않습니다.

실제 문서와 정답 파일은 읽지 않았습니다. 시안의 숫자는 측정 결과로 쓰지 않았습니다.

다른 사람 서버와 종료된 서버의 금액을 현재 서버 비용에 합치지 않습니다. 다른 앱 소유 실행 서버는 목록과 경고로 구분합니다.
