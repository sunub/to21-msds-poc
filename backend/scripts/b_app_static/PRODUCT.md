## Platform

web

## Users

- 기준 사용자: 이 프로젝트를 모르는 사람(20살, 개발 경험 조금). 처음 켜서 "지금 결과가 어떤지, 어디가 틀렸는지"를 10분 안에 알아야 한다.
- B 담당(추출 개발자, 매일): 실행 점수를 보고 안내문을 고쳐 항 하나를 다시 시험한다.
- A 담당(정답 초안·검수)과 C 담당(전처리): 가끔 들어와 결과 값과 원문을 대조한다. 서버를 만들거나 끄지 않는다.

## Product Purpose

안전보건자료(MSDS, 화학물질 안전 정보 문서)에서 모델이 뽑은 결과를 점수로 보여 주고, 틀린 값을 원문 쪽 그림·줄과 맞춰 보며, 항 하나만 다시 시험하고, 모델 서버를 올리고 내리는 내 컴퓨터 전용 작업 화면이다. 성공은 "처음 켠 사람이 안내 없이 실행 하나의 미달 항목에서 틀린 값 하나를 골라 원문 줄이 켜지는 것을 본다"이다.

## Positioning

실제 실행 기록(`runs/`)과 공식 채점기(`msds.evaluate.score`)를 그대로 쓴다. 화면의 점수는 터미널 비교표와 같은 숫자다. 가짜 샘플이 없다.

## Operating Context

- 내 컴퓨터(127.0.0.1:8765)에서만 열린다. 파이썬 표준 서버 하나, 브라우저는 Chrome·Safari (추정: 1440px 노트북 화면이 기본).
- 모델 서버는 SSH 터널 너머에 있다(RunPod은 시간당 과금, RNGD는 사내 장비 카드 4장). 연결이 없을 때가 흔하다.
- 평가용 문서 10건은 화면에 나오지 않는다(D-43). 쪽 그림·쪽 글자·안내문은 요청 때만 읽고 저장하지 않는다(D-47).
- 언어는 한국어. 용어: 실버(Claude가 만든 정답 초안), 가중 종합(항목 23개의 무게 평균), 필수 통과(필수 17개 중 목표를 넘은 수), 항(MSDS 16개 항), 안내문(모델에게 주는 지시문), 입력 판(쪽 글자 폴더 version9).

## Capabilities and Constraints

- 탭: 시작(새로), ① 점수판, ② 두 실행 비교, ③ 원문 대조, ④ 작업, ⑤ 서버("고급" 스위치를 켜야 보임), 도움말.
- 새 패키지·외부 주소(CDN·글꼴)·빌드 단계 금지. 표준 라이브러리, 인라인 SVG, 평범한 JS 한 파일(`app.js`), CSS 한 파일(`app.css`).
- 화면 코드에는 자동 시험이 없다. 사람이 읽는 글을 만드는 규칙은 파이썬(`b_app_text.py`)에 두고 pytest로 시험한다.
- 정보는 하나도 지우지 않는다. 요약을 먼저 보이고 세부는 접는다.
- 이번 작업은 다듬기(refinement)다. 밝은 바탕·카드·시스템 글꼴을 유지하고 위계·간격·글·색의 뜻을 고친다. 새 디자인이 아니다.

## Brand Commitments

이름 "B 작업 화면". 로고·브랜드 색 없음. 도구처럼 보여야 한다(마케팅 페이지가 아니다).

## Evidence on Hand

- 실제 실행 38개(`runs/`), 10/30 화면 캡처 5장(`~/.dev-browser/tmp/tab-*.png`, 세로 최대 3,453px), 도움말 `guide.html` 9장, 항목 설명 `ITEM_HELP` 23개(`b_app_runs.py`).
- 없음: 사용자 인터뷰, 사용 통계. 꾸며 내지 않는다.

## Product Principles

1. 요약 먼저, 세부는 펼침. 한 화면에서 "지금 상태"와 "다음에 할 일"이 보인다.
2. 이름은 사람 말로, 원래 표기는 작게 곁에. 폴더 이름·태그·변수 이름을 숨기지 않는다.
3. 용어는 그 자리에서 설명한다. 말풍선 하나로 끝낸다.
4. 오류는 "확인한 사실 + 할 일"이다. 예외 원문은 펼침 아래에 둔다.
5. 익숙한 도구 모양을 지킨다. 표준 선택 상자·단추·표. 장식과 움직임은 넣지 않는다.

## Accessibility & Inclusion

- 색만으로 뜻을 전하지 않는다. 색 옆에 글(통과/미달, 같음/다름)을 둔다.
- 말풍선은 키보드(포커스)로도 열린다. 단추는 `<button>`이다.
- 한국어 긴 글이 1280px 폭에서도 잘리지 않는다. 가로 스크롤이 생기지 않는다.
