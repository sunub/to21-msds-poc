## 핵심 판단

목표선과 호출 격자는 이 제품의 업무에 맞는다. 일반적인 카드 자체는 문제가 아니다.
사용자가 폴더 이름과 오류 문자열을 해석해야 하는 부분이 가장 큰 마찰이다.
확인한 우선순위는 P0 0건, P1 8건, P2 3건이다.
P0는 작업 전체를 막는 문제다. P1은 큰 혼란이다. P2는 우회할 수 있는 불편이다.

먼저 다룰 핵심은 다섯 가지다.

- 실행 이름을 사람이 읽는 말로 보여 준다.
- 점수판의 결론을 먼저 보여 주고 세부를 접는다.
- 틀린 값에서 원문 대조로 이어지는 길을 보인다.
- 오류에 확인한 사실과 다음 행동을 붙인다.
- 연결이 없을 때 실행할 수 있는 행동을 구분한다.
