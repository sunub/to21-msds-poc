# B 작업 화면 (개발 전용)

모델이 뽑은 값의 점수를 보고 원문과 맞춰 보는 화면입니다.
항 하나만 다시 시험할 수도 있습니다. 설계 결정은 ADR-025·027에 있습니다.
자세한 사용법은 "도움말" 탭(`b_app_static/guide.html`)에 있습니다.

## 처음 쓰기
처음 켜면 시작 탭이 열립니다. 주소에 탭 표시(`#score` 등)가 있으면 그 탭이 먼저 열립니다.
시작 탭에서 최근 실행의 점수를 봅니다.
지금 상태 카드에서 미달 항목의 "원문 대조로 →"를 누릅니다.
오른쪽에서 실버와 다른 값을 눌러 왼쪽 원문 줄이 노랗게 켜지면 안내가 끝납니다.
저장된 `runs/` 결과가 있으면 모델 서버 없이 할 수 있습니다.
탭 순서는 시작 + ① 점수판 + ② 두 실행 비교 + ③ 원문 대조 + ④ 작업 + (고급) ⑤ 서버입니다.
고급 스위치를 켜면 서버 탭이 보입니다. 도움말은 맨 뒤에 있습니다.
"시작 안내"로 돌아갈 수 있습니다. 시작·도움말의 "처음부터 다시 보기"는 안내 기록만 초기화합니다.
실행 데이터와 카드 접힘 상태, 고급 설정은 유지합니다. 안내를 닫거나 끝내면 다음 방문은 점수판으로 갑니다.

## 켜기
```
(cd backend && .venv/bin/python scripts/b_app.py)   # 127.0.0.1 에서만 열린다
```

## 파일
- `b_app.py`: 화면 요청을 받는 서버(표준 `http.server`)입니다. 탭의 데이터와 화면 파일을 줍니다.
- `b_app_text.py`: 표시 이름과 오류 안내를 만듭니다. 용어와 시작 안내 글도 한곳에 모읍니다.
- `b_app_runs.py`: `runs/` 읽기·채점(F의 `score_set`)·호출 격자·한도 분류·값 없는 행 뺀 점수·합격 기준.
- `b_app_diff.py`: 두 실행 비교, 하락 원인 문장, 안내문 버전 차이.
- `b_app_doc.py`: 쪽 글자 줄·그림 좌표, 결과 값↔줄↔실버 맞추기.
- `b_app_jobs.py`: 시험·본 실행·비교표를 하위 프로세스로 시작·중단하고 로그를 읽는다.
- `b_app_servers.py`: 모델 서버 상태, RunPod Pod·RNGD 모델 올리기·내리기(확인 토큰 2단계).
- `pod.py`: RunPod REST 도구(list·get·create·delete). 명령줄로도 쓴다.
- `try_section.py`: 항 하나·여러 개·문서 전체를 모델에 보내 단계별로 보여 준다.
- `b_app_static/`: `index.html`, `app.js`, `app.css`, `guide.html`(외부 주소 없음).
- `b_app_static/DESIGN.md`: 색·글자·간격과 공통 화면 요소의 디자인 기준입니다.
- `b_app_static/CRITIQUE.md`: 발견한 문제와 고친 내용, 검증 결과와 남은 한계를 기록합니다.

## 시험
```
(cd backend && .venv/bin/python -m pytest -q --ignore=tests/test_preprocess.py)
```
시험은 모델 서버와 네트워크를 부르지 않습니다.
`test_preprocess.py`는 실제 `data/pages/`를 덮어쓰므로 뺍니다.

## 보안 규칙
- 서버는 127.0.0.1에서만 엽니다. 다른 접속 대상(Host)이나 출처(Origin)의 요청은 거부합니다.
- `.env`의 RUNPOD_API_KEY와 모델 서버 키는 화면이나 기록에 쓰지 않습니다. 문서에는 변수 이름만 적습니다.
- 쪽 그림과 쪽 글자, 안내문은 요청 때만 보여 줍니다. 파일로 저장하지 않습니다(D-47).
- 평가용 문서는 받지 않습니다(D-43).
